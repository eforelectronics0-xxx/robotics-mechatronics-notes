How to use these notes

  • Open index.html in any browser. Click a topic name in the syllabus table below to open that topic.
  • Every topic page has its own table of contents, a Summary of key points and Review Questions at the end.
  • Use the Previous / Next buttons at the bottom of each page to move through the syllabus in order.
  • Use the Print button in the top bar to save a topic as a PDF or to print it for revision.
  • All files are plain HTML with embedded CSS, JavaScript and SVG. Copy the site folder anywhere — a pen drive, a phone or a college server — and it will work.
