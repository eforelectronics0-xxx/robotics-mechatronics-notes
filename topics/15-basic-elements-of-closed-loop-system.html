15Basic Elements of a Closed Loop System

Every element of a feedback control system explained in order, from the set point through the error detector, controller, actuator and plant, to the measurement element that closes the loop.

1.Structure of a Closed Loop System

A closed loop control system contains all the elements of an open loop system plus two more: a measuring element that observes the output, and a comparison point where the measurement is set against the desired value. The loop is therefore closed, and information about the output flows back to influence the input.

2.The Elements in Detail

  1. Set point / reference input (R) — the desired value of the controlled variable, expressed in the same units as the feedback signal. It may be set by a dial, a keypad, a switch, a program or a signal from a higher-level computer. Examples: 24 °C for a room, 1000 rpm for a motor, 2 m level in a tank.
  2. Feedback path / measurement element (H) — measures the controlled variable and converts it into a signal comparable with the set point. It usually consists of a sensor or transducer plus signal conditioning (amplifier, filter, ADC). This is the most critical element, because the accuracy of the whole system can never exceed the accuracy of the measurement. Examples: a bimetal strip or thermistor for temperature, a tachogenerator or encoder for speed, a float or pressure sensor for level, a strain gauge for force.
  3. Error detector / comparator (summing point) — produces the error signal e = R − B, where B is the feedback signal. In analogue systems this is a differential amplifier; in digital systems it is a subtraction performed in software; in a simple thermostat it is a mechanical comparison of two positions. The error may be positive (output too low) or negative (output too high).
  4. Controller — the element that decides what corrective action to take, based on the error. It may be purely analogue (a pneumatic or electronic amplifier), digital (a microcontroller, PLC or DSP running a control algorithm) or electromechanical. Common control laws are on-off, proportional, PI, PID, fuzzy logic and model predictive control. The controller output is called the manipulated variable.
  5. Final control element / actuator — the device that converts the controller's command into a physical action on the plant. Examples: a heater, a control valve, a motor, a solenoid, a damper, a pump. The actuator must have enough power, range and speed for the task.
  6. Plant / process — the physical system being controlled, for example the room, the motor and load, the tank of water, the chemical reactor. The plant has its own dynamics: lag, inertia, capacitance and resistance.
  7. Controlled output (C) — the actual value of the variable being controlled.
  8. Disturbance — an unwanted input that pushes the output away from the set point. Examples: opening a window in a heated room, a change in load torque on a motor, a change in inlet flow to a tank, a change in mains voltage.
  9. Power supply and interconnections — the energy sources and the signal wiring or communication bus.
Note

The manipulated variable is the quantity the controller changes (for example the heater power); the controlled variable is the quantity that results (the room temperature). A system may have several manipulated variables and several controlled variables, in which case it is called a multivariable system, and the loops can interact.

3.Step-by-Step Working of a Closed Loop System

  1. The set point R is entered by the user.
  2. The measurement element produces the feedback signal B proportional to the actual output C.
  3. The error detector computes e = R − B.
  4. If e = 0, the output is exactly at the set point and the controller holds its present output.
  5. If e ≠ 0, the controller produces a corrective command proportional to the size and sign of the error.
  6. The actuator applies this command to the plant, changing the output C.
  7. The change in C is measured again, the new error is computed, and the cycle repeats continuously.
  8. The system settles when the error is reduced to zero or to a small steady value within the acceptable band.

This continuous cycle of measure, compare, correct happens many times per second in an electronic controller. It is exactly what happens when you ride a bicycle: your eyes measure your position on the road, your brain compares it with where you want to be, and your arms turn the handlebars to reduce the difference. If a gust of wind pushes you sideways, the same loop corrects it automatically without any conscious decision.

4.Performance Requirements of a Closed Loop System

  • Stability — the most important requirement. The output must settle to a steady value and must not oscillate or diverge. A system with too much gain or too much delay can become unstable.
  • Accuracy — the steady-state error should be as small as possible, ideally zero.
  • Speed of response — the system should reach the set point quickly, with a small rise time.
  • Overshoot and damping — the output should not go far beyond the set point. A damping ratio of about 0.7 is usually aimed for.
  • Disturbance rejection — the output should be little affected by disturbances.
  • Robustness — the performance should not degrade much when the plant parameters change.
  • Sensitivity — the system should be insensitive to changes in its own components but sensitive to changes in the input.
  • Cost, reliability and maintainability — practical engineering constraints.

★Summary

  • A closed loop system contains a set point, an error detector, a controller, an actuator, a plant, a measurement element and a feedback path.
  • The error signal is e = R − B, where B is the feedback signal produced by the measurement element.
  • The measurement element is the most critical part, because the accuracy of the whole system is limited by the accuracy of the sensor.
  • The controller output is called the manipulated variable; the quantity being controlled is the controlled variable.
  • The system works in a continuous measure-compare-correct cycle, exactly like a person riding a bicycle.
  • Performance is judged by stability, accuracy, speed of response, overshoot, disturbance rejection and robustness.
  • Stability is the most important requirement; an over-enthusiastic feedback loop can oscillate.
  • Everyday closed loop systems include room heating, refrigerators, motor speed control, water level control, servo drives and vehicle cruise control.
