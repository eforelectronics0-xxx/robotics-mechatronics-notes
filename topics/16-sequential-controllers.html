1.What is Sequential Control?

Definition

Sequential control is a form of control in which a series of operations is carried out in a predetermined order, each step starting only when the previous step has been completed and its transition condition has been satisfied. The controller moves from state to state, and the sequence of states is fixed in advance.

Many industrial and domestic machines are naturally sequential. A washing machine must fill, then heat, then wash, then drain, then spin. A bottle filling machine must position the bottle, then fill, then cap, then label, then eject. A lift must close its doors, then move, then stop, then open its doors. In each case the order is fixed and skipping a step would be dangerous or useless — you must not spin a washing machine while it is full of water.

Sequential control is quite different from the continuous regulating control discussed in Topics 13 to 15. Regulating control holds a variable at a set value continuously (like room temperature); sequential control moves a process from one discrete state to another. Real machines often combine both: a washing machine has a sequential controller for the cycle and a closed loop regulator for the water temperature.

2.Structure of a Sequential Controller

Every sequential controller has the same three ingredients.

  • Steps (states) — each step is a condition of the machine during which certain outputs are ON. The machine is always in exactly one step (in a simple sequence).
  • Transition conditions — the logical condition that must become true before the machine may leave the present step and enter the next. This may be a sensor signal (a limit switch closed, a level reached, a temperature achieved), a timer expiry (5 seconds have elapsed), a counter value (20 parts counted), an operator command (start button pressed), or a combination.
  • Actions (outputs) — what the machine does during each step: open a valve, start a motor, switch on a heater, sound a buzzer.

The controller stores which step is currently active. When the transition condition of that step is satisfied, the controller deactivates the present step, activates the next one, and switches the outputs accordingly. This is exactly the behaviour of a finite state machine in computer science.

3.Types of Sequential Control

  • Event-based (sensor-driven) sequencing — the next step begins when a physical event occurs, such as a limit switch being operated, a part arriving at a station, or a level being reached. This is the safest and most accurate method because the machine only proceeds when the physical condition really exists.
  • Time-based sequencing — the next step begins after a fixed time has elapsed, using a timer. Simple and cheap, but it assumes the operation always takes the same time. If it does not (for example a slow-filling valve), the sequence goes wrong.
  • Counter-based sequencing — a step repeats until a count is reached, for example ten bottles filled or five holes drilled.
  • Combined (hybrid) sequencing — most real machines use both time and sensor conditions, for example “run the pump until the level switch operates OR until 60 seconds have elapsed, whichever comes first.”
  • Interlocked sequencing — additional safety conditions must also be true, for example the guard door must be closed and the emergency stop must be released.

Cam shaft sequencing

The oldest form of sequential control is a rotating shaft carrying a number of cams or dogs. As the shaft turns at a constant speed, each cam operates a limit switch at the correct moment, and the switches in turn control valves, clutches and motors. This method is extremely fast, reliable and repeatable, and is still used in automatic screw machines, packaging machines and printing presses. Its disadvantage is that changing the sequence means physically changing or repositioning the cams, so it is inflexible. An electronic equivalent is a cam timer or a drum sequencer, in which a rotating drum with studs makes contact with a row of fingers.

4.Devices Used as Sequential Controllers

  1. Cam shaft and limit switches — purely mechanical, very fast, fixed sequence.
  2. Drum sequencer / cam timer — a motor-driven drum or stepper-indexed disc with electrical contacts; the sequence is changed by moving the studs.
  3. Electromechanical timers and counters — on-delay and off-delay timers, star-delta timers, plug-in relays and mechanical counters wired together in a relay logic panel. Flexible to a limited extent but bulky and hard to modify.
  4. Programmable Logic Controller (PLC) — a rugged industrial computer programmed in ladder logic, function block, structured text or sequential function chart (SFC) language. The PLC scans its inputs, executes the program, updates its outputs and repeats, with a scan time of a few milliseconds. PLCs are the standard sequential controller in industry because the sequence can be changed by rewriting the program without touching the wiring.
  5. Microcontroller — a small, cheap programmable controller written in C or assembly, using a switch-case state machine. Used in domestic appliances, toys, automobiles and low-cost machines.
  6. Personal computer or industrial PC — used for complex sequences, data logging and operator interfaces.
  7. Hardware state machine — built from flip-flops and logic gates in a CPLD or FPGA, used where the sequence must be very fast or where the outputs must change simultaneously with no scan delay.

Sequential Function Chart and ladder logic

Modern PLC programming for sequences usually follows the Sequential Function Chart (SFC) method defined in the IEC 61131-3 standard. The chart is drawn as a series of steps (squares) joined by transitions (short horizontal bars), with the transition condition written beside each bar. Each step has one or more actions associated with it. The chart maps directly onto ladder logic using SET and RESET coils, or onto a microcontroller using a state variable.

Note

Practical rule for writing a sequence. Number the steps 0, 1, 2, 3 … Store the current step number in a register. The outputs are driven from the step number. A transition is tested only when its own step is active. Each transition SETs the next step and RESETs the current one in the same scan, so that two steps can never be active at once. Add an interlock so that the initial step can only be entered when the machine is safe (guards closed, emergency stop released).

5.Examples of Sequential Control

  • Automatic washing machine — fill → heat → wash → drain → rinse → spin → end. Transitions come from the level switch, the temperature sensor, timers and the door lock.
  • Traffic light controller — main road green → main road amber → main road red → side road green → and so on, driven by timers, or by vehicle detectors in the more advanced version.
  • Bottle filling machine — conveyor stops → nozzle lowers → fill valve opens until the level sensor operates → nozzle rises → conveyor runs to the next bottle.
  • Drilling machine — clamp the work → spindle on → feed down until the depth limit switch operates → dwell → retract → spindle off → unclamp.
  • Lift (elevator) — doors close → move to the floor → stop and level → doors open → wait for the door timer → doors close.
  • Pneumatic cylinder sequencing — A+ B+ B− A−, where each movement is confirmed by a magnetic reed switch before the next is started.
  • Dishwasher, microwave oven, vending machine, car park barrier, automatic gate, chemical batch plant and assembly robot — all sequential.

6.Advantages and Limitations

  • Advantages: the sequence is guaranteed and repeatable, so the machine always does the same thing; safety interlocks are built in, so a dangerous step cannot start unless the previous one has finished; easy to understand, to document and to troubleshoot because the state diagram shows exactly where the machine is; flexible to modify when a PLC or microcontroller is used; faults can be detected at each transition and an alarm raised if a step does not complete in time.
  • Limitations: not suitable for continuous regulation of a variable, which needs a feedback controller instead; a purely mechanical or timer-based sequence cannot adapt to changing conditions; if a sensor fails, the sequence may stop or, worse, may skip a step unless a watchdog timer is provided; programming and debugging a long sequence takes skill; the scan time of a PLC limits how fast transitions can be detected.
Important

Fail-safe design. Every transition that depends on a sensor should also have a maximum time limit, so that a stuck sensor does not stop the machine forever or let it proceed unsafely. For example: “wait for the level switch, but if 60 s elapse, stop and raise an alarm.” Emergency stop must be able to interrupt the sequence at any point and must return the machine to a safe state, not simply freeze it.

★Summary

  • Sequential control performs a fixed series of operations in a fixed order, each step starting only when the previous step's transition condition is satisfied.
  • The three ingredients of any sequential controller are steps (states), transition conditions and actions (outputs).
  • Sequencing may be event-based (sensor driven), time-based (timer driven), counter-based, combined or interlocked for safety.
  • Sequential control is different from regulating control; real machines often use both together.
  • Devices used as sequential controllers include cam shafts with limit switches, drum sequencers, electromechanical timer and relay panels, PLCs, microcontrollers, industrial PCs and hardware state machines.
  • A PLC programmed in ladder logic or Sequential Function Chart is the industrial standard because the sequence can be changed in software.
  • The Sequential Function Chart method uses numbered steps joined by transitions with conditions, and maps directly to SET/RESET ladder logic or to a switch-case state machine.
  • Every sensor-based transition should also have a time limit and an alarm, so that a failed sensor cannot cause an unsafe condition.
  • Typical examples are washing machines, traffic lights, filling machines, drilling machines, lifts and pneumatic cylinder sequences.
