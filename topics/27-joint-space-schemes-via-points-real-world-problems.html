27Joint Space Schemes, Via Points and Problems with Real-World Components

Planning a joint-space motion through several intermediate points, and an honest look at the imperfections of real hardware — backlash, friction, compliance, resonance, thermal drift and wear.

  2. Motion Through Via Points

1.Joint Space Schemes

In a joint space scheme the motion of every joint is planned independently as a function of time. The controller stores, for each taught point, the complete set of joint angles (θ1, θ2, …, θ6). Between two consecutive points it generates a smooth function for each joint. This is the scheme used for point-to-point motion, and it is the simplest, fastest and most robust way to move a robot.

Requirements of a good joint space scheme

  • The position must be continuous — no jumps.
  • The velocity must be continuous, ideally everywhere including at the via points, so that there is no infinite acceleration.
  • The acceleration should be continuous too, and bounded, so that the required torque stays within the motor's capability.
  • The motion should be as fast as possible without exceeding any limit.
  • The scheme should be simple to compute, because it must run in real time.
  • It should not produce unnecessary motion in joints that do not need to move.

Common joint space schemes

  1. Two-point move with a single polynomial — a cubic or a quintic polynomial takes each joint from its start angle to its end angle. Every joint is given the same total time so that they all arrive together.
  2. Two-point move with a trapezoidal velocity profile — the standard industrial method: constant acceleration, constant velocity, constant deceleration, with a parabolic position blend. Simple, predictable and fast.
  3. Multi-point move through via points with blended polynomials — a separate polynomial for each segment, joined so that the velocity is continuous at every via point.
  4. Spline interpolation — a single cubic spline is fitted through all the via points, giving continuous position, velocity and acceleration everywhere.
  5. Higher-order and time-optimal schemes — used where the motion must be as fast as the torque limits allow.

2.Motion Through Via Points

A via point (also called a way point, pass point or intermediate point) is a point that the robot must pass through on its way from the start to the goal. Via points are needed to avoid obstacles, to approach a workpiece from a safe direction, to follow a required path approximately, or to break a long move into safe pieces.

Two ways of treating a via point

  • Exact stop at the via point — the velocity is brought to zero at the via point and the next segment then accelerates from rest. This guarantees that the robot passes exactly through the point, but it wastes a great deal of time because the robot accelerates and decelerates at every point.
  • Blend (continuous) through the via point — the robot does not stop; the two polynomials are joined so that the position and the velocity are continuous, and the path is allowed to deviate from the exact via point by a specified tolerance. This is much faster and is the normal industrial practice. The tolerance is called the blend zone, corner distance or approximation zone.

Constructing a blended joint space trajectory

A standard method uses a cubic polynomial for each segment and imposes continuity of position and velocity at each via point.

  1. Let the via points be at times t0, t1, …, tn with joint values θ0, θ1, …, θn.
  2. For each segment k, write θk(t) = ak0 + ak1t + ak2t² + ak3t³.
  3. Impose θk(tk) = θk and θk(tk+1) = θk+1 (position continuity at both ends).
  4. Impose θ̇k(tk+1) = θ̇k+1(tk+1) (velocity continuity at the via point).
  5. Specify the velocity at each via point, either as zero (exact stop) or by a chosen rule, such as a fixed fraction of the maximum speed, or the value that makes the acceleration continuous as well.
  6. Solve the resulting set of linear equations for the coefficients.
  7. Check that the maximum velocity and acceleration in every segment are within the motor's limits; if not, increase the segment time and repeat.

If the acceleration must also be continuous at the via points, a quintic polynomial or a cubic spline is needed. A cubic spline through n+1 points requires solving a tridiagonal system of n−1 equations, which is very fast and is done once, off-line, when the program is prepared.

Timing of the segments

The time allotted to each segment is usually chosen in proportion to the largest joint movement in that segment, so that all joints finish at the same time and the motion looks coordinated:

tk+1 − tk ∝ maxi | θi,k+1 − θi,k | / ωi,max

The controller then checks that no joint exceeds its acceleration or torque limit, and lengthens the segment time if necessary. This process is called time scaling.

Example

Numerical. A joint must pass through the angles 0° at t = 0, 40° at t = 2 s and 90° at t = 5 s, with zero velocity at the start and at the end, and with the velocity at the via point chosen as 20 °/s. For the first segment, θ(t) = a0 + a1t + a2t² + a3t³ with θ(0) = 0, θ̇(0) = 0, θ(2) = 40, θ̇(2) = 20. From the first two conditions a0 = 0 and a1 = 0. Then 4a2 + 8a3 = 40 and 4a2 + 12a3 = 20, giving a3 = −5 and a2 = 20. So θ(t) = 20t² − 5t³, whose maximum velocity in the segment is 20 °/s at t = 1.33 s and whose acceleration at t = 0 is 40 °/s² and at t = 2 s is 0 °/s².

Note

Practical point. The path taken between via points in joint space is not the straight line between them in the workspace. If the tool must actually follow a straight line, the points must be closely spaced (a few millimetres apart) or Cartesian interpolation must be used instead. This is why a long joint move can look alarmingly like a wild swing to a person standing near the robot.

3.Some Problems with Real-World Components

All the theory above assumes an ideal robot: perfectly rigid links, frictionless joints, gears with no clearance, motors with unlimited torque and sensors with infinite resolution. Real robots have none of these properties. The differences between the ideal model and the real machine are the reason why robots must be taught on the actual workpiece, why calibration is needed for absolute accuracy, and why servo tuning is a skilled task.

1. Backlash

Backlash is the clearance between mating gear teeth, between a nut and a screw, or in a bearing. When the direction of motion reverses, the input must travel a small distance before the output begins to move. This produces a positioning error that depends on the direction from which the point was approached, and it shows up as a hysteresis loop in the accuracy test.

  • Effect: lost motion of a few arc-minutes, which at the end of a 1.5 m arm becomes a tool error of tenths of a millimetre; the servo loop may oscillate (limit cycling) as it hunts across the dead band.
  • Reduction: use harmonic drives or cycloidal reducers (near-zero backlash); preload planetary gears; use a preloaded double ball nut; use anti-backlash split gears with a spring; always approach a taught point from the same direction (the controller can be told to do this); preloaded bearings.

2. Friction and stiction

Friction in the gears, bearings and seals opposes motion. It has three components: stiction (static friction, higher than the others, which must be overcome before motion begins), Coulomb (dry) friction, which is roughly constant, and viscous friction, which is proportional to velocity.

  • Effect: a steady-state following error when the robot is moving; stick-slip motion at low speed, where the joint sticks and then jumps forward, giving a jerky crawl; contour errors when following a path; extra heat; difficulty in tuning the servo loop; limit cycling around the target.
  • Reduction: good lubrication; low-friction seals; harmonic drives instead of sliding contacts; friction compensation in the controller, which adds a torque command in the direction of motion; dither (a small high-frequency signal) to break stiction; higher servo gains; ball screws instead of plain screws.

3. Compliance (elastic deflection)

No component is perfectly rigid. Links bend, gear teeth deflect, shafts twist and bearings shift under load. This compliance means that when a force is applied at the tool, the actual tool position differs from the position calculated from the motor encoders, and the controller cannot see the error because the encoders are on the motor side of the gearbox.

  • Effect: positioning error proportional to the applied force; vibration and poor surface finish in machining; a limit to the force that can be applied in grinding or assembly; reduced bandwidth of the servo loop.
  • Reduction: stiffer structures and materials; higher-ratio gearboxes (which reflect the motor's stiffness up by the square of the ratio); a force/torque sensor at the wrist, which measures what is actually happening at the tool; direct-drive motors, which have no gearbox compliance at all; keeping the payload within the rating; mounting the tool close to the flange.

4. Resonance and vibration

Every robot structure has natural frequencies. If the motion excites one of them — at a sudden start or stop, at a particular speed, or through a repeating process force — the arm vibrates. Because a robot arm is a long, light, cantilever structure, its natural frequencies are low (a few hertz to a few tens of hertz), which is exactly the range of typical robot motion.

  • Effect: ringing after a move, which lengthens the settling time; poor surface finish; noise; increased wear; possible loss of accuracy or even damage.
  • Reduction: smooth acceleration profiles (S-curve instead of trapezoidal); jerk limiting; increasing the structural stiffness and moving the natural frequencies higher; input shaping, which adds a cancelling vibration to the command; notch filters in the servo loop tuned to the resonant frequency; damping material in the links; reducing the payload and the reach.

5. Thermal effects

Motors, gearboxes and brakes generate heat. Different materials expand at different rates, so the geometry of the arm changes as it warms up, and the position drifts. This is the main cause of the accuracy change between a cold machine and one that has been running for two hours. Lubricant viscosity also changes with temperature, altering the friction.

  • Reduction: thermal modelling and compensation in the controller; temperature sensors at critical points; a warm-up cycle before precision work; keeping the ambient temperature stable; using materials with a low coefficient of expansion for precision structures; allowing heat to escape from the motors.

6. Wear, ageing and clearance growth

Gear teeth wear, belts stretch, cables fray, lubricant degrades, bearings develop play, and seals harden. All of these increase backlash and reduce accuracy over the life of the machine. A robot that was accurate when new may be well outside its specification after ten years unless it is maintained.

  • Reduction: regular preventive maintenance — greasing, belt tension checks, cable inspection and backlash measurement; periodic recalibration; monitoring the motor current signature, which changes as the gearbox wears; keeping the machine clean and at the correct temperature.

7. Sensor quantisation, noise and delay

Encoders have a finite number of counts, so the measured position is quantised; the signal is noisy; and there is a delay in reading and processing it. After reduction through a high-ratio gearbox, the encoder resolution at the joint is excellent, but at very low speeds the quantisation still limits the smoothness of the velocity estimate.

  • Reduction: high-resolution absolute encoders (17-bit to 23-bit); velocity estimation by a filter rather than by simple differentiation; a higher servo update rate; resolver-to-digital conversion with good filtering; shielding of the encoder cables from electrical noise.

8. Actuator and drive limitations

Motors have a limited peak torque (available only for a few seconds before overheating) and a limited continuous torque. Power electronics have switching losses and a limited current. As a result, the robot cannot follow an arbitrarily fast trajectory, and the practical limit is set by torque, not by speed.

  • Reduction: correct motor and gearbox sizing using the RMS and peak torque calculations; reducing the inertia of the links; regenerative braking units so that energy recovered during deceleration is not wasted as heat in a braking resistor; gravity compensation so that holding torque does not consume the motor's rating.

9. Kinematic model errors

The Denavit-Hartenberg parameters used by the controller are the nominal dimensions from the drawing. The real robot differs because of manufacturing tolerances, assembly errors and deflection. These errors cause the calculated tool position to be wrong by a millimetre or more, even when every joint angle is perfect. This is why absolute accuracy is much worse than repeatability.

  • Reduction: kinematic calibration, in which a laser tracker or a ball-bar measures the actual tool position at many configurations, the DH parameters are identified by least-squares fitting, and a compensation table is downloaded to the controller. This can improve absolute accuracy from about 1 mm to better than 0.2 mm, which makes robots usable for machining and drilling.

Note

The overall lesson is that a robot is a feedback system built on imperfect components. Feedback corrects errors at the joint, but it cannot see errors between the joint encoder and the tool. That is why high-precision work needs either a sensor at the tool (vision or force) or a carefully calibrated machine.

★Summary

  • A joint space scheme plans each joint angle independently as a function of time; it must give continuous position and velocity, bounded acceleration, and maximum speed within the limits.
  • Common schemes are the single cubic or quintic polynomial, the trapezoidal velocity profile with parabolic blends, blended polynomials through via points, and cubic splines.
  • A via point may be an exact stop or a blend; blending is much faster and allows a specified path deviation.
  • Segment times are chosen in proportion to the largest joint movement so that all joints arrive together; time scaling then ensures the limits are met.
  • The path between via points in joint space is not a straight line in the workspace.
  • Real components introduce backlash, friction and stiction, compliance, resonance, thermal drift, wear, sensor quantisation, torque limits and kinematic model errors.
  • Backlash is reduced by harmonic and cycloidal drives, preloading and by always approaching from the same direction.
  • Friction is reduced by lubrication, friction compensation, dither and higher servo gains.
  • Compliance causes a tool error that the joint encoders cannot see; a wrist force/torque sensor or a direct drive is the remedy.
  • Resonance is reduced by S-curve profiles, jerk limiting, input shaping and notch filters.
  • Absolute accuracy is much worse than repeatability because of kinematic model errors; calibration with a laser tracker corrects this.
