13Control Systems — Feedback, Open Loop and Closed Loop Systems

The central idea of mechatronics: using feedback to make a system correct its own errors. Definitions, comparison, and the effects of feedback on accuracy, stability, sensitivity and disturbance rejection.

On this page

  1. Basic Definitions
  2. Feedback
  3. Open Loop and Closed Loop Systems

1.Basic Definitions

Definition

A control system is an arrangement of physical components connected together so as to command, direct or regulate itself or another system in order to achieve a desired objective. The quantity that is measured and controlled is called the controlled variable or output; the quantity that is applied from outside to obtain the desired result is the input or reference.

Control systems are everywhere: the human body regulates its temperature and blood sugar, a car cruise control holds a set speed, an air conditioner holds a set room temperature, a machine tool holds a set position, and a robot holds a set trajectory. In every case some quantity is measured, compared with what is wanted, and corrected.

  • Plant or process — the physical object or operation being controlled, for example a room, a motor, a chemical reactor.
  • Controller — the element that computes the corrective action, for example a thermostat, a microcontroller, a PLC.
  • Actuator — the element that applies the action to the plant, for example a heater, a motor, a valve.
  • Feedback element (sensor) — the element that measures the output and returns a signal proportional to it.
  • Error detector (comparator) — the element that subtracts the feedback signal from the reference and produces the error signal.
  • Disturbance — any unwanted input that tends to drive the output away from its desired value, for example opening a window in a heated room.
  • Set point — the desired value of the controlled variable.

2.Feedback

Definition

Feedback is the process of taking a portion of the output of a system and returning it to the input, where it combines with the reference signal to influence the subsequent output.

  • Negative feedback — the returned signal is subtracted from the reference. It reduces the error and is used in almost all control systems because it improves accuracy, reduces sensitivity to parameter variations, suppresses disturbances and widens the bandwidth.
  • Positive feedback — the returned signal is added to the reference. It increases the error and drives the system further away. It is used deliberately in oscillators, comparators with hysteresis (Schmitt triggers) and latching circuits, but in a control system it normally causes instability.

For a linear closed loop system with forward path gain G and feedback path gain H, the overall transfer function is

C / R = G / (1 + G H) and the effect of a disturbance D at the output is reduced by the factor (1 + G H)

This single expression explains everything about feedback. If GH is large (say 100), the output is almost entirely determined by H (the sensor) and hardly at all by G (the plant and actuator). This means that the accuracy of a closed loop system depends on the accuracy of its feedback element, which is why sensors are so important in mechatronics.

Effects of negative feedback

  • Gain is reduced by the factor (1 + GH).
  • Accuracy and linearity improve — errors caused by non-linearity or by parameter changes are divided by (1 + GH).
  • Sensitivity to parameter variations is reduced — if the plant gain G changes by 10 %, the overall gain changes by only about 0.1 % when GH = 100.
  • Disturbances are rejected.
  • Bandwidth increases — the system responds to a wider range of frequencies.
  • Noise is reduced if the noise enters inside the loop.
  • Stability may be reduced — this is the price paid. Excessive feedback with phase lag can make a system oscillate, so a controller must be properly designed and tuned.

3.Open Loop and Closed Loop Systems

Open loop (non-feedback) control system

Definition

An open loop system is one in which the output has no effect on the control action. The input determines the output, but the actual output is never measured and never compared with what was intended.

A classic example is a toaster or an electric clothes iron with only a manual setting. The user sets a dial, and the heater is switched on for a fixed time or at a fixed power. The toaster does not measure the colour of the bread; if the bread is thicker, colder or of a different type, the result will be different, and the toaster cannot know or care. Another example is a washing machine that runs a fixed timed sequence regardless of how dirty the clothes actually are.

  • Advantages of open loop systems: simple in construction and design; cheap; easy to maintain; no stability problem, since there is no feedback to cause oscillation; convenient when the output is difficult or expensive to measure; good when the input-output relationship is well known and the load does not vary.
  • Disadvantages: the output cannot be corrected automatically; it is inaccurate if there is any disturbance or any change in the system parameters; it needs periodic recalibration; it requires a well-known and predictable relationship between input and output; performance degrades with ageing and with environmental changes.

Closed loop (feedback) control system

Definition

A closed loop system is one in which the output is measured and fed back to be compared with the reference input, and the resulting error signal is used to correct the output.

An air conditioner is a closed loop system. The user sets a temperature (say 24 °C). A temperature sensor continuously measures the actual room temperature. The controller compares the two. If the room is warmer than 24 °C, the compressor runs; when the room cools to 24 °C, the compressor stops. If someone opens a window or the afternoon sun heats the room, the sensor notices the rise and the compressor runs again. The system automatically corrects for disturbances.

  • Advantages of closed loop systems: high accuracy, because errors are automatically corrected; less sensitive to variations in system parameters, to ageing and to non-linearity; disturbances are rejected; a wider bandwidth and better dynamic response can be obtained; nonlinearities and distortions are reduced; a relatively inaccurate and cheap plant can be made to give accurate results.
  • Disadvantages: more complex, so costlier; the feedback sensor must itself be accurate, or the whole system will be wrong; there is a risk of instability and oscillation, so the controller must be carefully designed and tuned; the system may respond more slowly; maintenance is more difficult; the sensor can fail or drift.

Real examples for comparison

Example

Traffic light. If a traffic signal changes at fixed times regardless of traffic, it is open loop. If it has detectors in the road and gives a green signal only when vehicles are waiting, it is closed loop.
Washing machine. A machine that washes for a fixed programmed time is open loop with respect to cleanliness. A machine with a turbidity sensor that keeps washing until the water is clear is closed loop.
Motor speed. A DC motor fed with a fixed voltage runs at a speed that depends on the load — open loop. The same motor with a tachogenerator feeding back its actual speed, and a controller adjusting the armature voltage, runs at a constant speed for any load — closed loop.
Stepper versus servo. A stepper motor driven by a pulse train is inherently open loop; a servo motor with an encoder is inherently closed loop.

Types of control action

  • On-off (two-position) control — the actuator is either fully ON or fully OFF. Simple and cheap, but the output oscillates within a band. Used in domestic thermostats, refrigerators and water level controllers.
  • Proportional (P) control — the controller output is proportional to the error: u = Kp e. Fast response but leaves a steady-state error called offset, because zero output requires zero error and a real load needs some output to hold it.
  • Integral (I) control — the controller output is proportional to the integral of the error. It eliminates the offset completely, but adds phase lag and can cause overshoot and oscillation.
  • Derivative (D) control — the controller output is proportional to the rate of change of error. It anticipates the future error and damps the response, but it amplifies noise and does nothing for a steady error.
  • PID control — the combination of all three, u = Kpe + Ki∫e dt + Kd(de/dt). This is the most widely used control law in industry, accounting for well over 90 % of all industrial control loops.
  • Sequential control — the system moves through a fixed sequence of steps, each step starting when the previous one's condition is met. Used in washing machines, packaging machines and traffic control.

★Summary

  • A control system directs or regulates a process so that a desired output is obtained. Its elements are the plant, controller, actuator, feedback element, error detector, set point and disturbance.
  • Feedback means returning part of the output to the input. Negative feedback reduces error and is used for control; positive feedback increases error and is used for oscillators and latching.
  • For a closed loop system, C/R = G/(1 + GH). Large loop gain makes the output depend mainly on the feedback element, so sensor accuracy is critical.
  • Negative feedback reduces gain but improves accuracy, linearity, disturbance rejection and bandwidth, and reduces sensitivity to parameter changes; it may reduce stability.
  • An open loop system does not measure its output, so it cannot correct errors. It is simple, cheap and always stable but inaccurate.
  • A closed loop system measures and compares its output, so it is accurate and rejects disturbances, but it is costlier, more complex and may oscillate.
  • Control actions include on-off, proportional, integral, derivative, PID and sequential control; PID is the most widely used in industry.
  • A stepper motor is naturally open loop; a servo motor is naturally closed loop.
